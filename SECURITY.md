# Security policy

Please report suspected security vulnerabilities privately. If private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on GitHub's Security tab. Do not disclose vulnerability details in a public issue or pull request.

If private reporting is unavailable, use a private contact channel provided by the repository maintainers on GitHub. This repository does not publish a separate security contact or response-time guarantee.

For non-sensitive bugs and feature requests, use the public issue forms.
