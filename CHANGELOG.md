# Changelog

Notable changes to this project are recorded here.

## 0.2.0 — 2026-10-29

- Complete weighted terminal reporting/comparisons, aggregate status, generic suite resume, structured diagnostics, and default weighted CLI imports.
- Persist experiment plans before inference; recover zero-run and orphaned passes; preserve suite portability and frozen identity.
- Add opt-in Ollama streaming TTFO, observed token usage/rate provenance, bounded exact polynomial equivalence, and stable raw-evidence/rescore identities.
- Add portable derived-report rendering, complete diagnostic CSV tables, and an installed-executable HTTP validation workflow.
- Bound timing summaries and avoid quadratic workbook writes; retain all raw observations in saved run artifacts.

- Add versioned weighted scoring, failure/missing penalties, separate prose/equation leaderboards, anchored accuracy bands, and conservative equation equivalence diagnostics.
- Add configuration version 3, three-pass defaults, an editable configuration wizard, shared offline HTML/Excel/CSV/JSON reports, and explicit measurement profiles.
- Add a shared PyTorch device service for CPU/MPS/CUDA/ROCm selection, normalized timing evidence, and local custom Python adapter lifecycle/capabilities.

- Add strict research eligibility checks, document/writer split protocols, and split-leakage audits with perceptual near-duplicate review findings.
- Add error inspection HTML, subgroup reports, formula-rendering and annotation metrics, external prediction import, and reproducible OCR baseline examples.
- Add versioned experiment suites with preview/resume, prompt and control variants, repetitions, and independent document-level reporting.
- Add bounded transient retries, cloud concurrency, per-invocation request/spend limits, response caching, run status, and JSON CLI output.
- Exclude cache hits from inference latency and observed provider usage/cost while retaining their predictions for accuracy and coverage.
- Add portable, immutable benchmark snapshots and separate-run comparison reports.
- Record benchmark fingerprints, scoring versions, dependency versions, and effective provider controls.
- Validate experiment settings before inference and resolve configured paths relative to their TOML file.
- Add paired image/text folders, dataset audits, document splits, frozen selections, and explicit preprocessing.
- Add TrOCR, official ChatGPT subscription sign-in, and separate OpenAI API adapters alongside Ollama.
- Add experiment configurations, dry runs, environment checks, and retries of failed samples.
- Separate prose, word, and equation reports; add paired confidence intervals and explicit cost scenarios.
- Keep old results exportable and preserve the legacy resume path.
- Add a local command-line benchmark for comparing Ollama vision models on IAM handwritten passages.
- Add IAM form validation, handwriting crop preparation, and XML-derived reference generation.
- Add CER, WER, exact-match, edit-count, latency, and reliability reporting.
- Add resumable runs and Excel, CSV, and JSONL result exports.
